# 🌸 Remindly – Personal Task & Reminder Manager

**Remindly** is a Python-based desktop application designed to help users manage their daily tasks and stay organized through timely reminders.

It provides a simple, aesthetic and user-friendly interface to keep track of important activities, deadlines and priorities.

##  Features

- **User Login:** Personal login and account management.
- **Task Management:** Add and manage daily tasks.
- **Priority Selection:** Organize tasks based on their importance.
- **Smart Reminders:** Receive reminders one hour before scheduled tasks.
- **Date & Time Selection:** Set deadlines using a calendar and 24-hour time format.
- **Profile Customization:** Choose from different avatar options and upload custom profile pictures.
- **Database Management:** Store user and task information using SQLite.
- **Aesthetic Interface:** Clean interface with attractive pastel themes.

## Technologies Used

- Python
- CustomTkinter
- SQLite
- Tkinter
- tkcalendar
- Pillow (PIL)

## Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/yarlagaddarithika14-git/Remindly.git
```

### 2. Open the project folder

```bash
cd Remindly
```

### 3. Install the required libraries

```bash
pip install customtkinter tkcalendar pillow
```

### 4. Run the application

```bash
python main.py
```
